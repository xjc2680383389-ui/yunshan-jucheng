> **《云山巨城》— 浏览器体素山水**
> 运行：双击 `start.bat`（自动启动本地服务并打开浏览器），或手动 `python -m http.server 8141` 后访问 `http://127.0.0.1:8141`。必须走本地服务打开（直接双击 index.html 会因浏览器安全限制无法加载）。
> 操作：**环绕**（默认）左键拖转、滚轮缩放、右键平移；**漫游**点击画布锁定指针后 WASD 移动、鼠标转视、Shift 加速、Esc 退出；**巡游**一键自动沿全城路线游览，空格退出。
> 昼夜：底部控制台可暂停/播放、拖动时间滑条任意设定时刻、切换流逝速度（60×/360×/1440×）。建议看 06:30 日出、19:00 日落与 21:00 灯火。
> 其他：右上「性能模式」为低配电脑准备（关阴影、雾拉近）；移动端支持环绕与巡游。
> 世界为程序化生成（固定种子，0.2m 体素，Three.js r160）。
