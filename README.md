# 云山巨城

一城山水，十二时辰。原创的浏览器三维体素作品。

## 打开

解压整个项目后，可双击 **index.html** 作为离线入口。代码不需要安装依赖，不需要联网。使用支持 WebGL2、开启硬件加速的现代浏览器。当前验证环境禁止访问 `file://`，因此已实测的运行方式是下面的本地服务。

也可以双击 **start.cmd**：有 Node.js 时启动本地服务并打开 `http://127.0.0.1:8186`；没有 Node.js 时直接打开页面。服务仅监听本机。终端中也可运行 `npm start` 或 `node server.js`，无须 `npm install`。

## 操作

- **观察**：左键拖动旋转，滚轮缩放，右键拖动平移；触屏单指旋转、双指缩放。
- **观景**：左侧四个观景点切换全景、瀑布、山顶和城内视角。
- **漫游**：点击“沿路漫游”，沿城门、溪桥、观澜阁旁的山道前往揽云亭；再次点击可独立暂停或继续。拖动可环顾，Esc 退出。
- **飞行**：点击“自由飞行”，拖动转向，W/S 前后、A/D 左右、Q/E 升降，Shift 加速。飞行提供地形避让；建筑可自由穿越。
- **昼夜**：底部滑条任意调节 0–24 小时；Ⅱ/▶ 或空格暂停、自动推进。默认两分钟走完一天，可改为一分钟、四分钟、十分钟或真实时间流速。调时后保持当前播放状态。
- **其他**：1–4 切换观景点，H 显隐界面，右上角 ⛶ 全屏，“?” 查看说明。“画质”在高分辨率和较低分辨率间切换。

## 场景

384 × 384 米主山城包含 183 栋古建，城墙与城楼、阶梯式街巷、溪桥、约 653 米连续游览道路、上城殿群、两级瀑布、七层观澜阁和主峰揽云亭。外围远山延续山岭尺度。

住宅与市肆有八种不同平面和轮廓：青瓦民居、马头墙宅、沿街商铺、围合院落、吊脚木楼、曲尺小院、重檐楼馆和山间粮仓；屋顶朝向、层高、材质、窗格、挑檐、阳台与庭院细节各有差异。支巷曲折、不等距，房屋采用疏密不同的街坊聚落分布，保留庭院、溪岸与空地；山台等高线也随地势起伏。

所有实体均遵循 **0.2 米 / voxel** 的坐标网格。实体表面和尺寸对齐 0.2 米整数格，相邻同材质体素合并成面或长方体绘制；山体宏观台阶、屋顶层叠和远山构件由多格体素组成，不改变基础体素大小。水体与瀑布也使用网格实体，流动通过颜色与明暗变化表达。

太阳与月亮连续沿天穹运行；天空、山间雾色、定向光、阴影、星辰与灯火随时间协调变化。黄昏渐亮、清晨渐暗，窗口与路灯采用发光材质和轻微光晕。日夜暂停只冻结日内时刻，溪水与瀑布仍在流动。

## 文件与验证

`index.html` / `style.css`：界面；`world.js`：确定性体素山城与道路生成；`app.js`：原创 WebGL2 渲染器、相机、昼夜与交互；`server.js`：可选本地服务；`verify.js`：生成数据检查。

全部代码、场景与着色器从零编写。**没有第三方依赖、外部引擎、外部模型、图片或字体。** 不参考或复用其他项目。

有 Node.js 时运行 `node verify.js`，检查建筑类型覆盖、朝向与行列分布、房屋占地重叠、所有实体与地形的网格对齐、路线离地高度、沿路相机与实体的相交，以及漫游终点。真实浏览器中的视觉与交互验证结果见 `验收记录.md`。

如浏览器报告 WebGL2 不可用，请开启硬件加速或换用支持 WebGL2 的浏览器。性能较低时切换“画质 · 流畅”。作品无需构建，直接分发本目录即可。
